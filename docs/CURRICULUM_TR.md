# 24 Haftalık İleri Veri Analisti Müfredatı

## Seviye sistemi

L1 temel operasyonel yeterlilik, L2 orta seviye üretkenlik, L3 ileri analiz, L4 modelleme/performance, L5 entegrasyon ve uzmanlık.

## Hafta 0 — Tanı

SQL: JOIN, GROUP BY, CTE, window functions, execution plan.
Qlik: load script, association, set analysis, variables, synthetic key/circular reference.
Python: core syntax, pandas, merge/groupby, datetime, dosya/API, performans.
Excel: dynamic arrays, lookup, Power Query, Data Model/Power Pivot, DAX.
English: teknik okuma, requirement ve error-message comprehension.

## Haftalar 1–4 — Eksik Temelleri Kapat

- SQL: NULL, CASE, data types, JOIN cardinality, GROUP BY/HAVING, CTE/EXISTS
- Qlik: LOAD/SQL SELECT, Resident/Preceding LOAD, ApplyMap, Exists, master calendar
- Python: collections, exceptions, pandas index/filter, groupby, merge
- Excel: XLOOKUP, SUMIFS, FILTER/UNIQUE/SORT, LET, Power Query merge/append
- Mini proje: günlük gelir ve doluluk raporu

## Haftalar 5–8 — Analitik Çekirdek

- SQL: ROW_NUMBER, RANK, DENSE_RANK, LAG/LEAD, running total, moving average
- Qlik: aggregation scope, Set Analysis, variables, dollar-sign expansion, YTD/MTD/LY
- Python: datetime/resample, rolling/expanding/shift, pivot_table/crosstab
- Excel: Data Model, relationships, DAX measures, CALCULATE, time intelligence
- Ara sınav

## Haftalar 9–12 — İleri Analiz

- SQL: recursive CTE, gaps/islands, cohort yaklaşımı, advanced window frames
- Qlik: alternate states, Aggr(), canonical calendar, comparative analysis
- Python: reusable functions, cohort/segmentation, profiling, validation
- Excel: LAMBDA, named functions, advanced Power Query ve DAX
- Case Study 1: Revenue neden düştü?

## Haftalar 13–16 — Modelleme ve Performans

- SQL: indexes, sargability, statistics, execution plans, query tuning
- Qlik: star/snowflake kararları, synthetic key, circular reference, QVD, incremental load
- Python: vectorization, memory usage, dtype optimisation, Polars karşılaştırması
- Excel: query folding, refresh strategy, model size, formula performance
- Ara sınav 2

## Haftalar 17–20 — Otomasyon ve Entegrasyon

- SQL Server → Python → Excel/Qlik pipeline
- API/JSON ingestion
- veri kalite kapıları ve reconciliation
- otomatik rapor üretimi
- loglama ve hata yönetimi
- Technical English: documentation + incident explanation

## Haftalar 21–24 — Capstone

Uçtan uca otel revenue analytics projesi:
1. SQL ile veri çıkar
2. Python ile temizle ve analiz et
3. Excel ile yönetim çıktısı üret
4. Qlik ile dashboard kur
5. İngilizce teknik özet yaz
6. final sınavı ve eksik konu tekrarı
